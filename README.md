# rohdomopo-ai

作業時間を短く、休憩時間を長くする「逆」ポモドーロタイマーです。

## 概要

このリポジトリは、[rohdomopo](https://github.com/igarin14pm/rohdomopo) というWebアプリを、GitHub Copilotのエージェントモードだけで書き直す練習として作成したものです。

通常のポモドーロ・テクニックとは逆に、5分間の作業と25分間の休憩を1セットとして扱います。無意味な徒労をできるだけ早く終わらせ、長い休憩時間を自由な創作に使うことを目指しています。

## 主な機能

- 5分間の作業フェーズと25分間の休憩フェーズのカウントダウン
- フェーズ終了時の自動切り替え
- 作業・休憩フェーズに合わせた画面の配色とメッセージの切り替え
- 開始、一時停止、再開に対応したタイマー操作
- カウントダウン中の音声通知
- 音声再生に関する注意ダイアログ
- 残り1分でタイマー表示を明滅させる視覚的な通知

## 使い方

このアプリはブラウザで動作する静的Webアプリです。JavaScriptのES Modulesを使用しているため、`index.html`を直接開くのではなく、ローカルHTTPサーバー経由で起動してください。

### 起動手順

1. [Node.js](https://nodejs.org/) をインストールします。
2. リポジトリのルートディレクトリで、次のコマンドを実行します。

   ```sh
   npx http-server
   ```

3. コマンドの出力に表示されたURLをブラウザで開きます。
4. 音声に関する注意ダイアログを閉じ、「カウントダウンを開始」を押します。

タイマー作動中にスマートフォンをスリープさせたり、ブラウザをバックグラウンドに移行したりすると、タイマーが正常に動作しない可能性があります。

## 技術構成

外部のJavaScriptライブラリやフレームワークは使用していません。
